# Code of Conduct

Masthead is a local-first tool that often sits next to private agent work. Contributors and maintainers keep discussion **direct, respectful, and technical**.

## Expected behavior

- Stay focused on the issue or pull request
- Assume local data and agent transcripts may be sensitive
- Give actionable feedback with enough context to reproduce or evaluate it
- Respect product boundaries and the documented security posture
- Prefer sanitized examples over real private work

## Unacceptable behavior

- Harassment, threats, personal attacks, or sustained disruption
- Publishing private session data, credentials, local database contents, or other sensitive material
- Pressuring maintainers or users to disclose private local workflow details
- Spam, drive-by self-promotion, or derailing threads

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; block participants; or restrict repository access when needed to keep the project safe and usable.

## Scope

This code of conduct applies to project spaces (issues, PRs, discussions) and to representations of the project in public channels when acting on behalf of Masthead.

## Contact

For conduct concerns that are not security vulnerabilities, open a private maintainer contact via GitHub (security reports still use [SECURITY.md](SECURITY.md)).
