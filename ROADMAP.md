# Roadmap

Masthead is pre-1.0. This list is directional, not a commitment calendar.

## Near-term

1. **Multi-machine** — track sessions live across multiple machines (priority).
2. **One-line try** — install-free or near-install-free path (e.g. `npx`-style launcher), modeled after smooth desktop tooling install UX.
3. **Windows desktop** — packaged Windows installer alongside macOS and Linux.
4. **Apple notarization / Developer ID** — replace adhoc macOS signing so download-and-open works without Gatekeeper workarounds.

## Not the focus right now

- Turning Masthead into a live monitoring tower, analytics dashboard, or task manager.
- Write-capable MCP tools without an explicit product decision.
- Cloud-required core operation (the product stays local-first).
