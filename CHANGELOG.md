# Changelog

All notable changes to Masthead will be documented in this file.

## 0.1.0

### Added

- Local-first Masthead daemon, Electron UI, canonical SQLite session graph, multi-harness live
  connectors, Workbench raw-to-publish pipeline, artifact-first Logbook, and read-only MCP access.
- Published session-dossier, runbook, ADR, and incident-timeline artifacts with evidence refs,
  multi-session provenance, per-artifact publication, N/A, and contribution resolution.
- Launch documentation for first-run import, Codex import, daemon API, MCP tools, configuration, session graph, and data paths.
- Repository health files and issue/PR templates.

### Changed

- README and OpenWiki now describe Masthead as an evidence-backed engineering-knowledge layer,
  with sessions as capture/provenance units and artifacts as Logbook/MCP reuse units.

### Fixed

- No fixed items recorded for this version yet.

### Security

- Documented read-only MCP boundary, local data handling expectations, and private vulnerability reporting path.
