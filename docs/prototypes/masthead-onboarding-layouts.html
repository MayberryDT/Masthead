Masthead onboarding layout and flow directions

Static HTML prototype. Five layout systems. Each option shows the full first-run flow.

01 Spine 02 Map 03 Ledger 04 Runway 05 Atlas
Problem to solve

The onboarding needs to feel like the app has taken over the workspace on purpose.

These options treat onboarding as a serious local setup workflow: detected harnesses first, metadata-only defaults, lazy Dossier hydration, optional provider configuration, and visible setup progress. No production code. No logic. Just layout and flow.

Option 01 / machined setup spine

Command Console Spine

A left-side progress spine anchors the wizard. The active step gets a large work surface in the middle, while the right rail always shows the exact choices and consequences. This is the most production-like direction.
